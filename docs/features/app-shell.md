# Оболочка приложения (шапка)

Общая навигационная шапка, которая отрисовывается на всех `protected`
страницах. Описана здесь один раз — остальные feature-файлы ссылаются
сюда вместо повторного перечисления состава.

## На каких страницах появляется

Шапка присутствует на всех `protected` страницах:

- `/` — список всех форм (см. [`forms-list.md`](./forms-list.md));
- `/me` — профиль пользователя (см. [`profile.md`](./profile.md));
- `/forms/new`, `/forms/:formId/edit` — конструктор
  (см. [`form-builder.md`](./form-builder.md));
- `/forms/:formId/responses` — список откликов
  (см. [`responses.md`](./responses.md));
- `/forms/:formId/responses/:responseId` — один отклик
  (см. [`responses.md`](./responses.md)).

Шапки нет на:
- `/login`, `/signup` — `unauthorized only`
  (см. [`auth.md`](./auth.md));
- `/forms/:formId` — `public` страница прохождения формы
  (см. [`form-fill.md`](./form-fill.md)).

## Состав

Шапка содержит четыре навигационных элемента (всегда в одном порядке):

| Подпись      | Действие                                                         |
|--------------|------------------------------------------------------------------|
| **Главная**  | Ссылка на `/`                                                    |
| **Новая форма** | Ссылка на `/forms/new`                                        |
| **Профиль**  | Ссылка на `/me`                                                  |
| **Выход**    | Завершает сессию и переходит на `/login` (см. [`auth.md`](./auth.md)) |

«Новая форма» при клике создаёт новый проект и сразу перенаправляет
в конструктор конкретной формы — детали в [`form-builder.md`](./form-builder.md).

## Конвенция «ссылка на ⟨страница⟩»

В описаниях контента страниц по всему проекту используется
конвенция: фраза «ссылка на ⟨название⟩ / ⟨URL⟩» означает, что при
клике на этот элемент происходит переход к указанной странице.
Примеры из ТЗ:

- **Ссылка «Войти»** — ссылка на `/login` ⇒ при клике переходим на `/login`.
- **Кнопка «Домой»** — ссылка на главную страницу ⇒ при клике
  переходим на `/`.

Эта конвенция не вводит каких-то новых требований к UI —
она просто сокращает описания.

## Связанные фичи

- [`auth.md`](./auth.md) — поведение «Выхода», доступы и редиректы.
- Все `protected`-страницы — встраивают эту шапку.
